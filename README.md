## 🚀 About Me

I am a **Full Stack Developer** specializing in **Software Design, Clean Architecture, and Scalable Distributed Systems**. Currently contributing to end-to-end advertising automation at **SaleAds.ai** and completing my **Commercial Software Engineering** degree at **Jala University**.

- 🔭 **Current Focus:** Developing scalable backend microservices, ad tech integrations (Meta Ads, Google Ads), and modern reactive frontends using spec-driven and agentic workflows.
- ⚙️ **Backend & Architecture:** Deep expertise in **Clean Architecture, Hexagonal Architecture, REST APIs**, and asynchronous processing pipelines using **C# / .NET Core, Node.js (TypeScript), and Java / Spring Boot**.
- 🎨 **Frontend Engineering:** Crafting accessible, modular, and fast web applications with **React, Next.js, Svelte, and TypeScript**.
- ⚡ **Performance & Asynchrony:** Experience designing concurrent & parallel processing engines (background workers, Web Workers) achieving up to **2x faster execution** on intensive media and data workloads.
- 🌐 **Languages:** Spanish (Native) • English (Professional Working Proficiency).
